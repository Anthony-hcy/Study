第二个问题，重新标定时，内参的fx、fy和cx、cy中主要变化的是谁
在第二个问题的基础上，如果主要变化的是内参的焦距fx、fy，如何根据无人机（搭载双目相机）相较于导线的位置来动态折算出焦距参数fx、fy
在静态时，计算三维坐标时采用的
$$s \cdot \begin{bmatrix} u \\ v \\ 1 \end{bmatrix} = M \cdot \begin{bmatrix} X \\ Y \\ Z \\ 1 \end{bmatrix}$$
其中：
s：尺度因子（深度相关的非零常数）；
u,v：像素坐标（对应代码中的X_left/Y_left、X_right/Y_right）；
M：投影矩阵（ML或MR），根据内参外参所得
最终A*[X;Y;Z] = B这个方程组，得到选点的三维坐标
那么，无人机搭载双目相机，动态过程如何得到选点的三维坐标呢
这一步在计算三维坐标时和静态有什么不同呢
我可以直接用我在静止时标定得到的参数来计算动态时的所选的三维坐标吗，式子不需要变化吗

- 内参和立体外参在无人机飞行中保持不变，无需重新标定。
动态测量时，只需在每帧图像上提取导线点的像素坐标，利用静态标定参数解算三维点。
弧垂计算通常只需要导线在相机坐标系下的相对三维坐标（例如拟合抛物线求最低点），无需转换到大地坐标，因此可直接使用静态参数。
如果确需世界坐标（如与设计值对比），则需要结合无人机上的GPS/IMU数据，将左相机坐标系下的坐标转换到地理坐标系，这相当于实时估计左相机的外参。

><font color="#d83931">Q、</font>但是，在无人机搭载双目相机拍摄导线时，无人机可能并不是水平的，拍出来的导线可能是倾斜的，此时选点计算的弧垂值不会发生偏移吗

1. 为什么直接计算会出错？（直观理解）
>**静态情况**：假设静态标定时相机水平放置。重建出的导线点位于一个**水平相机坐标系**下，该坐标系的Y轴（或Z轴）与重力方向对齐。此时，比较各点的Y值即可得到真实弧垂。
>**动态情况（无人机倾斜）**：当无人机发生俯仰或横滚时，相机坐标系随之倾斜。您用双目立体视觉（基于固定的内参和立体外参）重建出的导线点，是在这个**倾斜的相机坐标系**下的坐标。在此坐标系中，垂直轴不再与重力方向一致。如果直接使用该坐标系下的Y坐标计算弧垂，得到的将是**相对于倾斜平面的下垂量**，而非真实的重力弧垂。这好比用一把斜尺去测量垂直深度，结果必然失真。
2. 问题的本质
弧垂是一个具有明确物理意义的量，它指导线在**重力方向（垂直方向）**上的下垂程度。因此，要正确计算弧垂，必须在一个**垂直方向与重力对齐的坐标系**（如当地水平坐标系或世界坐标系）中进行。
之前的结论“动态测量可以直接使用静态参数”需要精确理解为：
> **静态标定的内参和立体外参可以准确重建出导线在任意时刻相对于当前相机坐标系的三维坐标。但要获得有物理意义的弧垂，必须将这些坐标从一个可能倾斜的相机坐标系变换到一个垂直方向与重力对齐的坐标系中。**
3. 解决方案：引入实时姿态信息
正确的处理流程分为三步：
> 1. 重建（静态参数立功）
使用静态标定的内参和立体外参，通过左右图像匹配点，解算出导线在**当前（倾斜的）左相机坐标系**下的三维坐标 $P_{\text{cam}} = (X_c, Y_c, Z_c)$。这一步准确反映了导线相对于倾斜相机的空间位置。
> 1. 矫正（引入实时姿态）
利用无人机上的IMU（惯性测量单元）提供的实时姿态数据（横滚角roll、俯仰角pitch、偏航角yaw），构建一个旋转矩阵$R_{\text{cam2level}}(t)$。该矩阵的作用是将倾斜相机坐标系下的点旋转到一个**水平坐标系**（如当地水平坐标系）中，在这个水平坐标系里，垂直轴与重力方向平行。公式为：$$P_{\text{level}} = R_{\text{cam2level}}(t) \cdot P_{\text{cam}}$$
其中 $R_{\text{cam2level}}(t)$ 随无人机姿态实时变化，由IMU数据计算得出。
> 1. 计算弧垂
在水平坐标系 $P_{\text{level}} = (X_l, Y_l, Z_l)$ 下，垂直方向（例如 $Y_l$）即为真正的重力方向。此时，您可以通过比较导线上各点的 $Y_l$ 坐标，拟合抛物线并计算真实的弧垂。

### 一、无人机姿态
![|415](https://pica.zhimg.com/v2-5480232b0c74e8d236044529bd170834_b.webp)![](https://i-blog.csdnimg.cn/blog_migrate/8dd05182d9f981c254c29774761849ce.png)![[2026.02.23-第三次会议-9.png|317]]
双目相机坐标系：左相机坐标系， x 右、y 下、z 前；
无人机机体坐标系： x 机头、y 右翼、z 机腹

相机系（倾斜后）坐标 
↓（R_CU：相机→无人机，把相机系的点转换到倾斜后的无人机机体系）
无人机系（倾斜后）坐标 
↓（R_UW：无人机倾斜后→水平时，把倾斜无人机系的点旋转回水平无人机系）
无人机系（水平/倾斜前）坐标 
↓（R_CU'：无人机→相机，把水平无人机系的点转换回水平相机系）
相机系（水平/倾斜前）坐标

1. 横滚角（Roll）旋转矩阵（绕 X 轴转）
$$
R_{roll} = R_{X}(\phi) = \begin{bmatrix}   1 &  0& 0\\  0 &  cos\phi& -sin\phi\\  0 &  sin\phi&cos\phi \end{bmatrix}\\
$$
2. 俯仰角（Pitch）旋转矩阵（绕 Y 轴转）
$$
R_{pitch}=R_{Y}(\theta) = \begin{bmatrix}   cos\theta &  0&sin\theta \\  0 &  1& 0\\   -sin\theta&  0&cos\theta \end{bmatrix} \\
$$
3. 偏航角（Yaw）旋转矩阵（绕 Z 轴转）
$$
R_{yaw}=R_{Z}(\psi) = \begin{bmatrix}   cos\psi& -sin\psi &0 \\   sin\psi& cos\psi & 0\\   0&  0&1 \end{bmatrix} \\
$$
4. 相机坐标系——>无人机坐标系 R_CU
相机z(前)—>无人机x(机头)、相机x(右)—>无人机y(右翼)、相机y(下)—>无人机z(机腹)
其旋转矩阵
$$
R_{CU}=\begin{bmatrix}   0& 0 &1 \\   1& 0& 0\\   0&  1&0 \end{bmatrix} \\
$$
5. 姿态角旋转矩阵 R_UW
$$
R_{UW}=R_{roll}R_{pitch}R_{yaw}=R_X(\phi)R_Y(\theta)R_Z(\psi)\\ 
$$
6. 总的旋转矩阵为
$$
R_{CW}=R_{CU}^TR_{UW}R_{CU}(相机坐标系——>无人机坐标系——>相机坐标系)
$$

```matlab
function w_point=h_manual_xyz(STR1,STR2,n,sec,roll,pitch,yaw)
    % h_manual函数：手动选点+双目匹配+无人机姿态旋转（y轴对齐重力方向）
    % 输入参数：
    %   STR1/STR2 - 左右图的图片路径
    %   n         - 手动选点的数量
    %   sec       - 选点等待秒数
    %   roll/pitch/yaw - 无人机姿态角（单位：度°），用于构造旋转矩阵
    % 输出参数：
    %   w_point   - 旋转后（y轴为重力方向）的三维坐标矩阵（N×3）
    % ========== 1. 读取并显示图片 ==========
    RGB1=imread(STR1);% 读取左图
    RGB2=imread(STR2);% 读取右图
    I1 = double(RGB1);% 转换为浮点数便于运算
    I2 = double(RGB2);
    % 左图手动选点
    figure,image(I1/255);
    axis image;
    hold on;
    title('1号摄像机图像');
    [X_left Y_left] = ginput2(n,sec); % 获得左图目标点坐标
    % 右图手动选点
    figure,image(I2/255);
    axis image;
    hold on;
    title('2号摄像机图像');
    [X_right Y_right] = ginput2(n,sec); % 获得右图目标点坐标
    % ========== 2. 读取相机标定参数 ==========
    % 左相机标定参数
    fid_left=fopen('D:\Workspace\Graduate\Code\ndcl\calib_left2.txt','r');
    ML=calib(fid_left);% 获取左相机投影矩阵
    fclose(fid_left);
    % 右相机标定参数
    fid_right=fopen('D:\Workspace\Graduate\Code\ndcl\calib_right2.txt','r');
    MR=calib(fid_right);% 获取右相机投影矩阵
    fclose(fid_right);
    % ========== 3. 校验选点数量，计算原始三维坐标 ==========
    if length(X_left)==0
        errordlg('左图标志点个数为零','提示');
        w_point = []; % 初始化输出，避免报错
    elseif length(X_right)==0
        errordlg('右图标志点个数为零','提示');
        w_point = [];
    elseif length(X_left)==length(X_right)
        % 调用match函数，得到相机坐标系下的原始三维坐标
        w_point_rotated = match(ML,MR,X_left,Y_left,X_right,Y_right)
        
        % ========== 4. 构造旋转矩阵并旋转坐标==========
        % 步骤1：校验姿态角参数是否为有效数值
        if ~isnumeric(roll) || ~isnumeric(pitch) || ~isnumeric(yaw)
            warning('姿态角参数非有效数值，将输出原始三维坐标');
            w_point = w_point_rotated;
            return;
        end
        % 步骤2：角度单位转换（度→弧度，MATLAB三角函数需弧度）
        Roll = deg2rad(roll);    % 横滚角转弧度
        Pitch = deg2rad(pitch);  % 俯仰角转弧度
        Yaw = deg2rad(yaw);      % 偏航角转弧度
        % 步骤3：构造单个轴的旋转矩阵（航空标准：Roll→Pitch→Yaw）
        % 绕X轴（横滚）旋转矩阵
        R_roll = [1,          0,           0;
                  0,  cos(Roll),  -sin(Roll);
                  0,  sin(Roll),   cos(Roll)];
        % 绕Y轴（俯仰）旋转矩阵
        R_pitch = [cos(Pitch),  0,  sin(Pitch);
                   0,          1,           0;
                  -sin(Pitch), 0,  cos(Pitch)];
        % 绕Z轴（偏航）旋转矩阵
        R_yaw = [cos(Yaw), -sin(Yaw),  0;
                 sin(Yaw),  cos(Yaw),  0;
                 0,          0,         1];
    % 4. 合成“无人机倾斜后 → 水平时”的正旋转矩阵 R_UW
	% 航空标准通常为外旋顺序 Yaw → Pitch → Roll (Z-Y-X)
	% 如果你的定义是内旋 Roll→Pitch→Yaw，保持下面的顺序即可
	R_UW = R_roll * R_pitch * R_yaw;  
	% 5. 构造“相机 → 无人机”的固定旋转矩阵 R_CU
	% 物理意义：P_U = R_CU * P_C （将相机系下的点转换为无人机系下的点）
	% 坐标系映射：相机z(前)→无人机x(机头)、相机x(右)→无人机y(右翼)、相机y(下)→无人机z(机腹)
    R_CU = [0, 0, 1;  % 无人机x = 相机z
            1, 0, 0;  % 无人机y = 相机x
            0, 1, 0]; % 无人机z = 相机y
	% 6. 合成“倾斜后相机 → 水平时相机”的总旋转矩阵 R_CW
	% （R_CU' 是 R_CU 的转置，正交矩阵的逆等于转置）
	R_CW = R_CU' * R_UW * R_CU; 
	% 7. 计算最终结果（从倾斜后坐标反推原始坐标）
	w_point = (R_CW * w_point_rotated')'
    else
        errordlg('匹配失败，左右图选点数量不一致','提示');
        w_point = [];
    end
end
```

### 四、获取无人机姿态角

>无人机一般内置 IMU（陀螺仪 + 加速度计），部分集成磁力计。
1. 大厂成品无人机已完成姿态解算，可通过手册或 SDK 直接读取 Roll/Pitch/Yaw 或四元数；
2. 开源 / 自制平台需自行读取 IMU 原始数据，通过滤波等融合算法解算姿态。
- 互补滤波（简单、轻量）
- Mahony 滤波（常用、开源飞控标配）
- Madgwick 滤波（精度更高）
- 卡尔曼滤波 / 扩展卡尔曼 EKF（高精度方案）

>其中 Roll/Pitch 可由 IMU 融合得到，Yaw 航向角必须依赖磁力计才能获得绝对角度，同时需注意机体与世界坐标系的定义及旋转顺序。
