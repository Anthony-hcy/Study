# 41篇双目视觉、无人机视觉与输电线路导线弧垂观测计算文献精读汇总

## 2009-基于计算机视觉的输电线弧垂测量-李俊芳

**摘要：** 该文较早将计算机视觉引入输电线弧垂测量，建立了“相机标定—双目立体视觉—图像匹配—三维坐标恢复—曲线拟合—弧垂计算”的完整流程。论文从针孔成像模型出发，分析世界坐标、相机坐标、图像坐标和像素坐标之间的转换关系，通过左右图像同名点匹配恢复输电线目标点三维坐标，再拟合导线曲线计算弧垂。

**关键重要公式：**

$s[u,v,1]^T = K[R t][XW,YW,ZW,1]^T；Z = fB/d，d = xL - xR；f = zAB(xs) - z(xs)。$

## 2011-采用图像摄影的输电线路弧垂测量方法-陈斯雅 等

**摘要：** 该文面向无人机巡线场景，将数字图像处理与摄影测量技术结合，提出利用无人机多视角现场照片测量输电线路弧垂的方法。方法先通过平滑滤波、Sobel 边缘检测和边界追踪提取导线轮廓，再确定弧垂点像平面坐标；随后结合像片内外方位元素，利用共线方程和立体像对前方交会求取弧垂点物方空间坐标。

**关键重要公式：**

$x - x0 = -f[a1(X-XS)+b1(Y-YS)+c1(Z-ZS)]/[a3(X-XS)+b3(Y-YS)+c3(Z-ZS)]；y - y0 = -f[a2(X-XS)+b2(Y-YS)+c2(Z-ZS)]/[a3(X-XS)+b3(Y-YS)+c3(Z-ZS)]；f = HAB(Ps) - H(Ps)。$

## 2011-基于航拍序列图像的输电线弧垂测量方法-仝卫国 等

**摘要：** 该文将航拍序列图像等效为运动双目或多目视觉系统，利用飞行平台连续运动形成的基线恢复导线特征点三维坐标。文献选取间隔棒作为自然特征目标，采用归一化互相关匹配和小波金字塔分层搜索提高匹配效率，再通过立体视觉模型恢复间隔棒中心空间坐标，最后利用非线性最小二乘拟合导线空间曲线并计算最大弧垂。

**关键重要公式：**

$RNCC = sum[(I1-I1mean)(I2-I2mean)] / sqrt[sum(I1-I1mean)^2 sum(I2-I2mean)^2]；min sum ||Pi - C(ti)||^2；f = HAB(xm) - HC(xm)。$
