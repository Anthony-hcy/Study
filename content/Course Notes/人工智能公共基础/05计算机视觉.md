- 计算机视觉是 AI 贴近生活的方向，应用于刷脸解锁、自动驾驶、AI 绘画等。
- 自动驾驶实现分为“看见”和“看懂”两步。
- **传感器系统**：
  - 摄像头：利用立体视觉或单目估算距离，但受强光、黑暗、雨雪影响。
  - 毫米波雷达：波长 1-10 毫米，穿透力强，不受恶劣天气影响，可测距测速。

- **算法处理**：
  - 立体匹配算法计算视差图转深度图。
  - 拼接点云形成环境模型。
  - 多传感器数据融合。
- **理解与决策**：
  - 深度学习框选目标，语义分割算法分类道路、行人等。
  - 应用场景扩展至仓储物流、家用机器人、无人机巡检、医疗手术定位。
  - 需要高性能计算平台实时处理。

## 基本概念与发展历程 [05:19](https://bpschool.oss-cn-qingdao.aliyuncs.com/exam_content%2F1%2F1787464338858_vvaiw5.mp4?response-content-disposition=inline&OSSAccessKeyId=LTAI5tAMWGCHNwUNVTgp8TcU&Expires=1787554373&Signature=sLozUSoBwD50GebXjBJoJcGrnj0%3D#t=319)

- **定义**：计算机视觉是让机器像人一样看懂世界，流程分三层：
  - 输入层：接收图片、视频、深度画面。
  - 处理层：深度学习特征提取，自动解析信息。
  - 输出层：针对下游任务输出结果（如识别物体、追踪轨迹）。
- **发展历程**：
  - 几何主导期：数学模型重建形状与空间结构。
  - 手工特征期（90年代）：SIFT、HOG 结合 SVM 推动目标识别。
  - 深度学习期（2012年起）：AlexNet 引领 CNN 时代，大幅提升分类识别性能。
  - 生成式 AI 期（2020年至今）：Transformer 和扩散模型实现从文字生成图像、视频和三维内容，完成从“看”到“造”的跃迁。

## 核心任务一：图像分类 [08:46](https://bpschool.oss-cn-qingdao.aliyuncs.com/exam_content%2F1%2F1787464338858_vvaiw5.mp4?response-content-disposition=inline&OSSAccessKeyId=LTAI5tAMWGCHNwUNVTgp8TcU&Expires=1787554373&Signature=sLozUSoBwD50GebXjBJoJcGrnj0%3D#t=526)

- **定义**：判定图片主体对应的类别标签（如猫、狗、马）。
- **实现流程**：
  - 特征提取：多层网络提取边缘、纹理、形状，层层抽象为复杂物理特征。
  - 分类判断：特征输入全连接网络，输出各类别概率，选取最高概率作为结果。
- **里程碑**：
  - ImageNet 数据集：超大规模标注数据库，提供海量训练素材。
  - AlexNet：2012 年在 ImageNet 竞赛中错误率大幅降低，证明深度卷积网络能力，开启 CV 繁荣时代。

## 核心任务二：目标检测 [11:50](https://bpschool.oss-cn-qingdao.aliyuncs.com/exam_content%2F1%2F1787464338858_vvaiw5.mp4?response-content-disposition=inline&OSSAccessKeyId=LTAI5tAMWGCHNwUNVTgp8TcU&Expires=1787554373&Signature=sLozUSoBwD50GebXjBJoJcGrnj0%3D#t=710)

- **定义**：不仅识别类别，还要定位物体位置。
- **任务内容**：
  - 目标分类：识别所有物体类别（车牌、行人等）。
  - 边界框定位：用矩形框标出坐标及大小。
  - 结果可视化：显示方框、类别及置信度分数。
- **应用场景**：
  - 自动驾驶：实时检测车辆、行人、信号灯，辅助决策系统减速、避让。
  - 智慧安防：24 小时自动识别非法入侵、人员逗留、遗留行李等异常情况并预警。

## 核心任务三：图像分割 [14:52](https://bpschool.oss-cn-qingdao.aliyuncs.com/exam_content%2F1%2F1787464338858_vvaiw5.mp4?response-content-disposition=inline&OSSAccessKeyId=LTAI5tAMWGCHNwUNVTgp8TcU&Expires=1787554373&Signature=sLozUSoBwD50GebXjBJoJcGrnj0%3D#t=892)

- **定义**：像素级视觉任务，给每个像素分配类别，解析场景轮廓。
- **分类**：
  - 语义分割：将像素分类到对应类别（行人、车、天空），不区分同类别不同实例。
  - 实例分割：在语义分割基础上区分同一类里的不同个体（如汽车 A 和汽车 B），精度更高。
- **应用场景**：
  - 医疗领域：CT/MRI 影像智能分析，自动区分器官、肿瘤，辅助手术规划和诊断。
  - 遥感图像：卫星图像自动划分土地类型（居民区、耕地、河流等），用于城市规划、生态监测、灾害评估。

## 核心任务四：图像生成（AIGC） [17:12](https://bpschool.oss-cn-qingdao.aliyuncs.com/exam_content%2F1%2F1787464338858_vvaiw5.mp4?response-content-disposition=inline&OSSAccessKeyId=LTAI5tAMWGCHNwUNVTgp8TcU&Expires=1787554373&Signature=sLozUSoBwD50GebXjBJoJcGrnj0%3D#t=1032)

- **对比传统 AI**：
  - 传统判别式 AI：解决“图片里有什么”，进行识别、判断、预测。
  - 生成式 AI：解决“能不能生成新图片”，创造全新内容。
- **工作流程**：输入文本提示词或参考图片，AI 理解需求后生成全新图像，可人工微调。
- **应用实例**：
  - 文本生成图像：如生成穿着中国古代铠甲的足球运动员哈兰德。
  - 图像编辑与风格转换：如将真人照片转换为《龙珠》漫画风格。
  - 视频生成：如北京理工大学出品的关于傣族传统村落形成的叙事视频，展示村落布局、建筑风格及生态智慧。

## 实操案例：YOLOv10 实时目标检测 [26:13](https://bpschool.oss-cn-qingdao.aliyuncs.com/exam_content%2F1%2F1787464338858_vvaiw5.mp4?response-content-disposition=inline&OSSAccessKeyId=LTAI5tAMWGCHNwUNVTgp8TcU&Expires=1787554373&Signature=sLozUSoBwD50GebXjBJoJcGrnj0%3D#t=1573)

- **YOLO 系列优势**：开源、内置预训练权重无需从零训练、速度快精度高、普通电脑即可运行。
- **实验流程**：
  1. **环境配置**：
     - 检查 Python 版本（3.10）及路径。
     - 安装 PyTorch 深度学习框架（推荐 CUDA 版本以利用 GPU 加速）。
     - 安装其他依赖库。
  2. **安装 YOLOv10**：
     - Git 下载官方源码。
     - 进入目录安装 requirements.txt 中的依赖包。
  3. **加载预训练模型**：
     - 下载 yolov10n 轻量化模型权重。
     - 加载模型结构与参数，创建推理模型。
  4. **输入测试视频**：
     - 定义视频路径并检查存在性。
     - 使用 OpenCV 读取视频宽度、高度、FPS 等信息。
  5. **执行目标检测**：
     - 设置参数：source（输入视频）、save=True（保存结果）、device=0（使用 GPU）。
     - 模型逐帧读取、预测、绘制边界框并保存。
  6. **展示结果**：
     - 安装视频转换依赖，将 AVI 格式转为 MP4 以便播放。
     - 播放检测结果视频，观察车辆、行人的识别框及置信度分数。

### 思考
1. **[为什么自动驾驶汽车不能仅仅依靠摄像头，还需要搭配毫米波雷达和激光雷达？](https://bibigpt.co/search?q=%E4%B8%BA%E4%BB%80%E4%B9%88%E8%87%AA%E5%8A%A8%E9%A9%BE%E9%A9%B6%E6%B1%BD%E8%BD%A6%E4%B8%8D%E8%83%BD%E4%BB%85%E4%BB%85%E4%BE%9D%E9%9D%A0%E6%91%84%E5%83%8F%E5%A4%B4%EF%BC%8C%E8%BF%98%E9%9C%80%E8%A6%81%E6%90%AD%E9%85%8D%E6%AF%AB%E7%B1%B3%E6%B3%A2%E9%9B%B7%E8%BE%BE%E5%92%8C%E6%BF%80%E5%85%89%E9%9B%B7%E8%BE%BE%EF%BC%9F)**
  - 单个或多个摄像头在强光、黑暗、雨雪、雾霾等恶劣天气下容易受到图像质量的影响；而毫米波雷达能穿透雨雪雾，激光雷达则可以通过反射精确构建三维点云图，多传感器融合可以取长补短，确保行车安全。

2. **[传统的判别式AI与现在的生成式AI有什么本质的区别？](https://bibigpt.co/search?q=%E4%BC%A0%E7%BB%9F%E7%9A%84%E5%88%A4%E5%88%AB%E5%BC%8FAI%E4%B8%8E%E7%8E%B0%E5%9C%A8%E7%9A%84%E7%94%9F%E6%88%90%E5%BC%8FAI%E6%9C%89%E4%BB%80%E4%B9%88%E6%9C%AC%E8%B4%A8%E7%9A%84%E5%8C%BA%E5%88%AB%EF%BC%9F)**
  - 传统判别式AI（如分类、检测）的核心是识别、判断和预测，回答的是“图片里有什么”；而生成式AI的核心是创造全新的内容，能够根据输入的提示词或参考图片创作出原本并不存在的图像或视频。


### 术语解释
- **计算机视觉 (Computer Vision)**: 人工智能的核心分支之一，旨在让电脑和机器模仿人类视觉系统，接收并解析图片、视频等原始视觉素材，从而看懂整个世界。
- **图像分类 (Image Classification)**: 计算机视觉中最基础的任务，给定一张图片，模型自动判定其主体并输出对应的类别标签。
- **目标检测 (Object Detection)**: 比图像分类更进一步的任务，不仅要识别出图中有哪些物体，还要用矩形边界框标出它们在图像中的具体位置、大小及置信度。
- **图像分割 (Image Segmentation)**: 一种像素级的极细视觉任务，为图片里的每一个像素点分配对应的类别，实现从粗略识别到完整解析场景轮廓的升级。
- **YOLOv10**: 全球最主流的实时目标检测算法系列之一，具备开源、内置预训练权重、速度快且精度高的优势，非常适合零基础开发者上手使用。
