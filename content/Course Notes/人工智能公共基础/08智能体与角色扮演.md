## 引言：数字人对话案例 [00:18](https://bpschool.oss-cn-qingdao.aliyuncs.com/exam_content%2F1%2F1787464417726_44engn.mp4?response-content-disposition=inline&OSSAccessKeyId=LTAI5tAMWGCHNwUNVTgp8TcU&Expires=1787556475&Signature=xRy2acgOhBPXcrEe8XBwnfc7lL0%3D#t=18)

- 视频以数字人钱学森和乔布斯关于“下一代智能”的对话开场，展示不同背景人物对同一问题的差异化回答。
- **钱学森观点**：智能应服务人类，核心是人机结合的辩证思维体系；强调综合集成专家系统与人脑思维（抽象、形象、直感）；主张立足马克思主义哲学，解决形象思维与直感思维理论问题，实现人机协同进化。
- **乔布斯观点**：反对“像人”或“超越人”的二元论，主张智能应是“心灵的自行车”，处理人类不擅长的数据任务，提供无感界面，注重创造价值与体验而非单纯理解世界。
- 对话揭示两种角色立场：一种基于科学规律、系统工程和社会责任（钱学森）；另一种基于产品创新、用户体验和创造价值（乔布斯）。

## 角色扮演的定义 [07:40](https://bpschool.oss-cn-qingdao.aliyuncs.com/exam_content%2F1%2F1787464417726_44engn.mp4?response-content-disposition=inline&OSSAccessKeyId=LTAI5tAMWGCHNwUNVTgp8TcU&Expires=1787556475&Signature=xRy2acgOhBPXcrEe8XBwnfc7lL0%3D#t=460)

- **基本概念**
  - 角色扮演是让模型在对话中以特定角色身份进行思考和交流。
  - 不仅回答问题，还需保持角色的知识背景、表达方式、思考角度和行为边界。
- **实现机制**
  - 通过系统提示词（System Prompt）设定：你是谁、你知道什么、怎么说话、不能做什么。
  - 真正的角色设定包含专业知识、沟通风格、领域经验、价值观和行为边界，使输出更适应具体场景。
- **角色类型与应用**
  - **类型**：真实人物（如钱学森、乔布斯）、虚拟人物（小说、游戏角色）、职业身份（教师、医生等）。
  - **应用场景**：教育（历史人物数字人）、医疗（AI 导诊）、新闻主持、智能服务等。
  - 不同场景要求不同：历史人物重知识还原，专业角色重准确性与边界，主持人重表达稳定性。

## 角色扮演的演进与方法 [11:59](https://bpschool.oss-cn-qingdao.aliyuncs.com/exam_content%2F1%2F1787464417726_44engn.mp4?response-content-disposition=inline&OSSAccessKeyId=LTAI5tAMWGCHNwUNVTgp8TcU&Expires=1787556475&Signature=xRy2acgOhBPXcrEe8XBwnfc7lL0%3D#t=719)

### 大模型前的方法

- **固定脚本**：预设对话流程，优点可控，缺点缺乏灵活性，无法处理脚本外内容。
- **规则匹配**：识别关键词调用回复规则，比脚本灵活，但不理解语境，易僵硬或答非所问。
- **浅层心理建模**：识别用户情绪标签（如疲惫、焦虑）并匹配策略，具备初步共情，但理解仍较浅，依赖预定标签。

### 大模型时代的方法

- **基于提示词（Prompt）**
  - 将角色背景、关系、资料写入提示词。
  - **优点**：简单、无需训练、修改方便；**缺点**：依赖提示词完整性，长对话易遗漏信息或“出戏”。
- **基于微调（Fine-tuning）**
  - 收集大量符合角色特点的对话数据进行训练（如 LoRA）。
  - **优点**：语言风格稳定，无需每次输入长设定；**缺点**：数据准备成本高，修改不灵活。
- **基于 Skill 的方式（OpenCrawl）**
  - **核心理念**：不仅模仿语言，更封装角色的认知方式、判断原则和行为边界，使其能参与分析决策。
  - **构建六步骤**：
    1. **数据收集**：从书籍、访谈、社交媒体等收集信息。
    2. **信息解析**：多智能体并行提取关键观点、行为模式。
    3. **认知提取**：总结心智模式、决策启发式、价值观、表达风格。
    4. **验证过滤**：通过一致性、长期记忆、独特性验证减少错误。
    5. **构建 Skill**：整理成标准化技能文件（核心认知、使用说明、边界约束等）。
    6. **调用执行**：智能体根据任务主动调用 Skill，以角色思维方式输出结果。
  - **优势**：相比 Prompt 告诉模型“是谁”，Skill 告诉模型“怎么思考和行动”，更接近可持续使用的角色智能体。

## 角色扮演所需数据 [18:48](https://bpschool.oss-cn-qingdao.aliyuncs.com/exam_content%2F1%2F1787464417726_44engn.mp4?response-content-disposition=inline&OSSAccessKeyId=LTAI5tAMWGCHNwUNVTgp8TcU&Expires=1787556475&Signature=xRy2acgOhBPXcrEe8XBwnfc7lL0%3D#t=1128)

- **Prompt 数据**
  - **零样本**：仅提供名称、描述、口头禅。
  - **少样本**：加入少量事例对话学习风格。
  - **多轮对话数据**：体现不同情境下的回应方式，为 Skill 构建提供支撑。
- **微调数据**
  - 采用指令-输入-输出格式，大量样本训练使模型稳定学习角色特征。
  - **关键**：数据质量决定模型学到的是特征还是机械口头禅，需覆盖丰富场景。
- **Skill 数据**
  - **来源**：高质量权威资料（传记、演讲、访谈等），不仅记录言语，更包含经历、理念、决策方式。
  - **提取内容**：核心观点、表达习惯、思考方式、典型案例、行为边界。
  - **目标**：还原角色完整的认知体系，而非仅收集口头禅。

## 案例与实践 [23:09](https://bpschool.oss-cn-qingdao.aliyuncs.com/exam_content%2F1%2F1787464417726_44engn.mp4?response-content-disposition=inline&OSSAccessKeyId=LTAI5tAMWGCHNwUNVTgp8TcU&Expires=1787556475&Signature=xRy2acgOhBPXcrEe8XBwnfc7lL0%3D#t=1389)

- **乔布斯角色卡局限**
  - 虽能模仿语言风格（短句、反问、三点式结构），但未必真正运用其思考逻辑，存在“说得像”但“想得不像”的问题。
  - **改进方向**：需进一步提取价值观、判断标准、决策方式。
- **“钱老大脑”案例**
  - **核心思路**：通过知识统筹和模型训练模拟钱学森的知识结构和思维方式。
  - **数据基础**：1821 封书信、125 篇文章，提取 2 万多条语句，涵盖科学技术体系、系统科学、马克思主义哲学等。
  - **技术实现**：基于 ChatBIT 大模型，结合知识图谱、向量数据库、人类反馈强化学习，实现知识推理而非简单检索。
  - **意义**：从模仿语言走向模仿知识和思维，提供更深入的技术路线。
- **课程实践作业**
  - 安装 OpenCrawl 并接入程序。
  - 选择熟悉角色，利用 Nuwa Skill 蒸馏出角色 Skill。
  - 启动 Skill 进行多轮对话，评估蒸馏质量。
