本教程将指导你通过 **OpenList** 和 **RaiDrive**，将阿里云盘等网盘挂载为本地硬盘，方便直接在“我的电脑”中访问和管理。

## 一、工具简介

### 1. OpenList
- **功能**：网盘中转服务，能将阿里云盘、百度网盘等挂载为本地磁盘，通过 WebDAV 协议提供访问接口。
- **项目特点**：开源免费，上线两周获 1 万多星，200+ 开发者参与。
- **支持网盘**：阿里云盘、百度网盘、夸克网盘、123网盘等。

### 2. RaiDrive
- **功能**：将网络存储映射为本地磁盘，支持 WebDAV 等多种协议，映射后盘符在文件管理器中与本地硬盘无异。

---

## 二、OpenList 安装与初始配置

### 1. 下载与解压
- 访问 OpenList 官网，在 `releases` 页面下载适合你系统的版本（如 Windows 64位）。
- 将压缩包解压到专用文件夹（如 `openlist`）。

### 2. 启动服务
- 在 OpenList 文件夹路径栏输入 `CMD` 回车，打开命令行。
- 执行命令：
  ```cmd
  openlist server
  ```
- 如遇防火墙提示，点击“允许访问”。
- **重要**：记录命令行窗口显示的 **初始密码** 和 **端口号**。

### 3. 初次登录与修改密码
- 浏览器访问 `http://127.0.0.1:你记录的端口号`
- 用户名：`admin`，密码：粘贴初始密码。
- 登录后进入 **管理** → 修改密码 → 保存，并用新密码重新登录。

---

## 三、挂载阿里云盘（示例）

1. 在 OpenList 左侧菜单点击 **存储** → **添加驱动**。
2. 选择 **阿里云盘**。
3. **挂载路径** 填写 `/阿里云盘`（斜杠开头，名称自定）。
4. **获取刷新令牌**：
   - 在 OpenList 官方文档中找到“获取令牌” → 选择阿里云盘。
   - 使用阿里云盘 App 扫码登录并授权。
   - 复制生成的 **刷新令牌**。
5. 将令牌粘贴回添加页面，点击 **添加**。
6. 状态显示 `work` 即表示挂载成功。

---

## 四、配置 WebDAV 权限（关键步骤）

1. 进入 OpenList 管理界面 → **管理** → **用户**。
2. 找到 `admin` 用户，点击 **编辑**。
3. 勾选 **WebDAV 读取** 和 **WebDAV 管理**。
4. 保存设置。

---

## 五、RaiDrive 安装与本地磁盘映射

### 1. 安装与登录
- 从 [RaiDrive 官网](https://www.raidrive.com/) 下载安装。
- 启动后登录你的 RaiDrive 账号。

### 2. 添加网络驱动器
- 点击 **添加** 按钮。
- **服务类型**：`WebDAV`
- **连接设置**：
  - 取消勾选“地址”栏。
  - 地址：`127.0.0.1`
  - 端口：`5244`（OpenList 默认 WebDAV 端口）
  - 路径：`/DAV`
- **账户信息**：
  - 用户名：`admin`
  - 密码：你修改后的 OpenList 密码
- 点击 **连接**。

### 3. 连接成功
完成后，在“我的电脑”中会新增一个盘符（如 Z:），即可像本地硬盘一样浏览、编辑网盘文件。

## 六、设置开机自动启动

### 1. 创建启动脚本
在 OpenList 文件夹下新建 `openlist start.vbs`，内容如下：
```vbscript
CreateObject("WScript.Shell").Run "openlist server",0
```
（可选）创建 `stop.vbs` 用于停止服务。

### 2. 添加到开机启动项
- 右键 `start.vbs` → 创建快捷方式。
- 按 `Win + R`，输入 `shell:startup` 回车，打开启动文件夹。
- 将快捷方式剪切到该文件夹中。
- 重启后 OpenList 将自动后台运行。

## 七、参数速查表

| 项目 | 值 |
| :--- | :--- |
| **OpenList 默认用户名** | `admin` |
| **WebDAV 端口** | `5244` |
| **WebDAV 路径** | `/DAV` |
| **本地访问地址** | `http://127.0.0.1:5244` |
| **开机启动文件夹** | `shell:startup` |

---

## 八、注意事项

- 每次开机需确保 OpenList 服务已启动，RaiDrive 才能正常映射。
- 同一局域网内，其他设备可通过本机 IP + 端口（如 `http://192.168.x.x:5244`）访问。
- 建议定期备份 OpenList 文件夹下的配置文件。
